Reminder Technical Guidance
Browser Window Requirement: Web-based browser notifications require an open tab or active browser session. If your device shuts down, goes to sleep, or terminates the browser process, push triggers resume when the browser is next opened.
Audio Alert Chime: SmartMed utilizes synthesized Web Audio API frequencies (E5 • B5 chime) to produce crisp alerts without downloading external audio files.
Mobile Use: On mobile browsers (Chrome, Edge, Safari 16.4+), you can add SmartMed to your home screen for rapid access and proactive alerts.
